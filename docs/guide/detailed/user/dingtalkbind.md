# 钉钉绑定配置教程（企业内部机器人）

适用场景：将文件推送至客户端，不依赖于钉钉应用

## 一、前提条件

在开始绑定前，请确认满足以下条件：

- **邮箱验证**：YC账号需已完成邮箱验证
- **账号权限等级**：您的YC账号等级需达到1级或以上
- **钉钉账号**：您需拥有一个有效的钉钉账号

## 二、在个人中心获取绑定指令

1. 登录YC控制台，进入 **“个人中心”**。
2. 点击**绑定钉钉**
3. 点击 **获取绑定指令**
4. 系统将生成一串指令，如： **#绑定用户 {"dingtalk_token":"abcde"}**（示例）：
5. 点击**复制命令**，复制该指令，后续配置中会用到

2. 真实姓名与申请理由均可填写任意内容

## 四、在“全体群”中找到机器人并私聊配置

1. 在钉钉中找到您所在企业的 **“全体群”**（YCService）
2. 找到机器人**YC文件传输**
3. 点击机器人头像，进入其详情页
4. 点击 **“发消息”**，进入与机器人的单聊窗口
5. 粘贴**第二步**得到的指令，点击 **发送**
6. 如果一切顺利，您将得到回复:**"绑定YC账号成功，用户名: ...，钉钉StaffId: ..."**

## 五、常见问题（FAQ）

| 问题                         | 解决方法                                                  |
| ---------------------------- | --------------------------------------------------------- |
| 获取指令时提示“账号等级不足” | 联系管理员提升账号权限                                    |
| 找不到“YC文件传输”           | 尝试将企业切换至YCService后使用钉钉搜索框搜索“YC文件传输” |
| 绑定时提示失败               | 尝试重新获取绑定指令                                      |
| 私聊机器人无响应             | 联系管理员                                                |
